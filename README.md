# Customer Shopping Behavior Analysis

An end-to-end data analytics portfolio project exploring retail customer purchasing patterns, customer segments, product preferences, discounts, subscriptions, and revenue.

## Project Overview

Retail businesses collect customer transaction and shopping-preference data, but raw data alone does not explain customer behavior. This project uses Python, SQL, and Power BI to prepare and analyze customer shopping data, answer business questions, and present the results in a dashboard and supporting reports.

The dataset contains **3,900 customer records and 18 fields**, including customer demographics, purchased items, product categories, purchase amounts, review ratings, subscription status, shipping type, discounts, previous purchases, payment methods, and purchase frequency.

## Business Objectives

- Understand purchasing patterns across customer groups and product categories.
- Compare revenue and average purchase amounts across customer segments.
- Examine the relationship between subscriptions, repeat purchases, and spending.
- Evaluate discount usage across products.
- Review product ratings and shipping preferences.
- Present key metrics and patterns in an interactive Power BI dashboard.

## Project Workflow

1. **Data understanding:** Load the CSV file and inspect its structure, data types, summary statistics, and missing values.
2. **Data cleaning and preparation:** Fill missing review ratings using the median rating within each product category, standardize column names, and prepare analysis-ready fields.
3. **Feature engineering:** Create age groups and convert purchase-frequency labels into an approximate number of days.
4. **SQL analysis:** Load the prepared data into a SQL database and answer business questions using queries.
5. **Visualization:** Use the Power BI report to communicate customer and purchasing patterns.
6. **Reporting:** Review the supporting business problem document, analysis report, and presentation.

## Business Questions Answered with SQL

The SQL script includes queries addressing these questions:

1. What is the total revenue generated by male and female customers?
2. Which customers used a discount but spent at least the average purchase amount?
3. Which five products have the highest average review ratings?
4. How do average purchase amounts compare between Standard and Express shipping?
5. Do subscribers spend more? Compare customer counts, average spend, and total revenue.
6. Which five products have the highest percentage of purchases with discounts?
7. How many customers fall into New, Returning, and Loyal segments?
8. What are the top three most purchased products within each category?
9. Among repeat buyers with more than five previous purchases, how many have subscriptions?
10. What is the revenue contribution of each age group?

**SQL concepts demonstrated:** `SELECT`, `WHERE`, `GROUP BY`, `ORDER BY`, aggregate functions, subqueries, `CASE`, CTEs, and `ROW_NUMBER()` window functions.

## How to Run the Project

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd <your-repository-folder>
```

### 2. Set up Python

Install Python, then install the libraries used by the notebook:

```bash
pip install pandas numpy sqlalchemy psycopg2-binary pymysql pyodbc jupyter
```

You only need the database driver for the SQL database you choose. For SQL Server, install the appropriate Microsoft ODBC Driver separately.

### 3. Run the notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open `Customer_Shopping_Behavior_Analysis.ipynb` and run the cells in order. Keep `customer_shopping_behavior.csv` in the same project folder, or update the file path in the notebook.

The notebook includes data import, exploration, cleaning, feature creation, and examples for connecting to a SQL database.

### 4. Load the prepared data into SQL

- Create a database named `customer_behavior` (or update the database name in the notebook).
- Configure the connection details for PostgreSQL, MySQL, or SQL Server.
- Run the notebook's relevant database connection and data-loading section.
- Open `customer_behavior_sql_queries.sql` in your SQL client and execute the analysis queries.

**Important:** Update the sample database username, password, host, port, and database name for your own environment. Never commit real passwords or other credentials to GitHub. The SQL script uses PostgreSQL-style `::numeric` casting in one query; if you use MySQL or SQL Server, adjust that expression to the syntax supported by your database.

### 5. Explore the Power BI dashboard

Open `customer_behavior_dashboard.pbix` using Power BI Desktop. If the report prompts you to reconnect to a data source, configure it to use your local SQL database and the prepared customer table.

### 6. Review the project deliverables

- `Business Problem Document.pdf` — business context and problem definition.
- `Customer Shopping Behavior Analysis.pdf` — supporting analysis report.
- `Customer-Shopping-Behavior-Analysis.pptx` — project presentation.
